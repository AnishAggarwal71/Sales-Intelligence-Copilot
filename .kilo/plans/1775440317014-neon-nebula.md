# Plan: Run Streamlit Dashboard

## Goal
Start the Sales Intelligence Copilot Streamlit dashboard and fix connection issues

## Problem
The dashboard at http://localhost:8501 is not accessible (Connection refused)

## Steps
1. Check if Streamlit is already running:
   - Open a terminal and run: `tasklist | findstr streamlit` (Windows)
   - Or check if port 8501 is in use: `netstat -ano | findstr 8501`
2. If Streamlit is not running, start it:
   - Navigate to the project directory: `cd D:\Python_AI_Projects\sales-intelligence-copilot`
   - Activate virtual environment: `venv\Scripts\activate`
   - Run: `streamlit run app.py`
3. Wait a few seconds for the server to start
4. Open http://localhost:8501 in the browser

## Notes
- Sample data can be generated separately if needed with `python data/generate_data.py`
- The app works with sample data or uploaded CSVs
- If port 8501 is already in use, Streamlit may use a different port (8502, etc.)
